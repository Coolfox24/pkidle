# Ocean sprites

Each runtime PNG is a separate transparent 32×32 frame. Files are named by building ID; certificate and signing-key are shared sprites. Keep the 32×32 canvas when adding frames later so animation does not jump between positions. Ambient fish and seaweed assets are retained as source material but are not displayed in the game.

The active jellyfish animation has eight aligned 32×32 frames per palette (`jellyfish-{cyan,blue,orange,red}-v2-0.png` through `-7.png`) and horizontal 256×32 strips (`jellyfish-{color}-v2.png`). Each palette also has a preview GIF. `prepare-jellyfish-v2.py` normalizes the generated sources using shared frame bounds. CSS plays eight frames at 600ms each for a 4.8-second loop with a gentle six-second bob; reduced-motion mode uses a static frame. The earlier four-frame assets remain available as source material.

Signing ceremony colours: RSA-512 cyan; RSA-1024 and RSA-2048 blue; RSA-3072 orange; RSA-4096 and Hybrid/PQC red. `PixelJellyfish` selects the palette from the current CA level, including when restoring a saved game.

Eight-frame generation prompt (built-in image tool, four-frame sheet as edit reference): Create an EIGHT-frame idle pulse loop, FOUR COLUMNS and TWO ROWS, equal square cells on transparency. Preserve the cyan jellyfish identity, navy eyes and smile, coarse 32×32 pixel style. Use subtle successive in-between poses: neutral, mildly compress, compress, mildly expand, expand, recover with tentacles right, nearly neutral, return to neutral with tentacles left. Keep body center, scale, eyes and baseline fixed with padding. Flat limited palette, no antialiasing, blur, textures or labels. Smooth transition from last frame to first for a slow 4.8-second loop.

Recolour prompt (built-in image tool, eight-frame cyan sheet as edit reference; one generation per colour): Change ONLY cyan/turquoise body and tentacle colours to blue / orange / red with matching highlights and shadows. Preserve navy outlines, eyes, smile, every pose, silhouette, pixel positions, scale, padding, the four-column two-row grid and transparency. No new shapes, detail, text, background or blur. All eight frames use the same palette; this is a palette swap.

Animation generation prompt (built-in image tool, existing jellyfish as edit reference): Create four frames in one horizontal row, preserving the friendly cyan 32×32 pixel jellyfish. Neutral bell, compressed bell with tentacles left, expanded bell with tentacles right, recovery to neutral. Keep the face identity, body center, scale and baseline fixed. Coarse square pixels, limited flat palette, transparent background and padding; no labels, bubbles or environment.

Created using the built-in image generation tool. `ocean-source-v2.png` is the selected coarse source. `prepare-ocean-assets.py` crops and normalizes the generated subjects into individual 32×32 frames with nearest-neighbor resizing and alpha preservation.

Final generation prompt: Simplify the ocean atlas into authentic low resolution retro pixel art, preserving the 4×4 ordering and subjects. Use coarse 16×16 logical shapes, large flat square pixels, limited colors, no gradients, no text, and transparent padding. Rows: jellyfish/shrimp clicker/human diver/coral signing station; anemone connectors/broadcasting pearl shell/octopus workstation/fish enrollment school; shield clam/crab carrying certificate/double workstation octopus/interconnected coral pods; Windows-style certificate/gold signing key/tiny fish/seaweed. The generated source was then normalized to individual 32×32 game frames.
